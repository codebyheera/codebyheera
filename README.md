### 📌 Featured Projects

#### 🌙 Al-Quran Hub ⭐
A free, ad-free, non-profit Quran web application built for the Ummah. Read all 114 Surahs, listen to 5 beautiful reciters, navigate by Juz, bookmark Ayahs, and search the entire Quran — completely free, no login required, works on all devices.

**Built with:** React · Node.js · Express · Supabase · Cloudflare CDN · Vercel

🔗 [Live Site](https://alquranhub.org)
💻 [Source Code](https://github.com/codebyheera/al-quran-app)
