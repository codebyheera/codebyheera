## 🌙 Featured Project

### Al-Quran Hub

A free, ad-free Quran platform designed to provide a clean and distraction-free Quran experience for Muslims worldwide.

#### Features

- 📖 Complete Quran (114 Surahs)
- 🎧 Multiple Audio Reciters
- 📚 Juz Navigation
- 🔍 Powerful Quran Search
- 🔖 Bookmark Ayahs
- 📱 Responsive Design
- ⚡ Fast Global Delivery with Cloudflare CDN
- 🔐 No Login Required
- ❤️ Completely Free

#### Tech Stack

React • Node.js • Express.js • Supabase • Cloudflare • Vercel

🔗 **Website:** https://alquranhub.org

💻 **Repository:** https://github.com/codebyheera/al-quran-app

> **No ads next to Allah's words. Ever. Purely Lillah 🤲**
